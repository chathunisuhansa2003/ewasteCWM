CARBON CALCULATOR LOGIN - HOSTINGER SETUP
==========================================

1. Open Hostinger hPanel.
2. Go to Websites -> Manage -> Databases -> Management.
3. Create a new MySQL database and database user.
4. Open phpMyAdmin for that database.
5. Select Import, choose database.sql, and run the import.
6. Open config.php and replace these values with your Hostinger details:
   - DB_HOST
   - DB_NAME
   - DB_USER
   - DB_PASS
7. Upload all project files into public_html. Keep the same folder structure.
8. Ensure SSL/HTTPS is enabled for the website.
9. Open your website and click Carbon Calculator.
10. Create a test account, sign in, test the calculator, then test Logout.

IMPORTANT
---------
- Other website pages can remain as HTML files.
- Do not share config.php or your database password publicly.
- The old carbon.html has been replaced with protected carbon.php.
- Every Carbon Calculator link now opens auth.php. Logged-in users are sent
  automatically to carbon.php.
